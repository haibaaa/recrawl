# recrawl — a freshness-aware recrawl scheduler

Track T4, Option A ("freshness-aware recrawl scheduler") for the CSD358 IR hackathon.
A polite news crawler that decides **what to re-fetch** with a per-URL change-rate ×
staleness × importance policy, plus a small search index whose ranking blends
tf-idf cosine with crawler-derived quality signals.

## How it works

```
RSS seeds ──► frontier ──► polite fetcher ──► trafilatura extraction
                            │                    │
                          robots.txt          store (pages, versions, fetch_log)
                            │                    │
                     fresh news articles ◄──── loop: score() → rank → budget
                                                │
                                ┌───────────────┴────────────────┐
                     change detector                     replay simulator
                     shingle Jaccard                      policies × budgets
                     (plus CC digests)                     → freshness curves
                                    │
                           search index (lnc.ltc + zones + g(d))
```

- **Crawl loop** wakes every `--interval` seconds, runs a pass with a per-pass
  fetch `--budget`, and records *every* page's byte/stripped/shingle fingerprints plus
  the volatile-stripped ground-truth so the history is fully replayable offline.
- **Recrawl policy** (`proposed`) ranks URLs by `λ̂ × staleness × importance`,
  where `λ̂` is a Laplace-smoothed per-fetch change probability; baselines are
  round-robin, random, and static importance. An `oracle` policy (knows future
  change times) bounds what a good policy could achieve.
- **Change detection** compares ordered sets of k=5 content shingles (Jaccard, τ=0.85),
  with byte-hash and volatile-stripped-hash baselines. Common Crawl snapshot payload
  digests act as an *independent* external oracle.
- **Search** is a standard inverted index (Porter stemmer, stopwords), lnc.ltc cosine
  with a title-zone weight of 2.0, a Robertson BM25 baseline, and a blended
  `net = cosine + α·g_importance + β·g_freshness` (α=β=0.01) ranking.

## Modules

| Module | Responsibility |
| --- | --- |
| `normalize.py` | canonical URL handling (`host_of`, tracking-param stripping) |
| `robots.py`, `fetcher.py` | robots.txt cache, polite HTTP fetch with backoff |
| `frontier.py` | URL de-duplication, per-host crawl delay, discovery queue |
| `store.py` | SQLite: pages, versions, fetch_log, pass history |
| `extract.py`, `detect.py` | trafilatura extraction; shingle/Jaccard + hash detectors |
| `seeds.py` | international news RSS seeds (BBC, Guardian, Al Jazeera, DW) |
| `scheduler.py` | recrawl policies + replay simulator |
| `cc.py` | Common Crawl index queries, WARC range fetch, snapshot pairs |
| `indexer.py`, `search.py`, `textproc.py`, `porter.py`, `stopwords.py` | search index + ranking |
| `evaluation.py` | detector P/R, freshness curves, search P@k ablation |
| `metrics.py`, `cli.py`, `config.py` | scoring containers, CLI, constants |

## CLI

```
recrawl seeds                        # Discover seed URLs from RSS feeds
recrawl crawl --budget 25            # One crawl pass
recrawl loop --interval 600 --passes 120 --budget 600 --cap 500   # live loop
recrawl status                       # DB summary
recrawl cc-label --limit 120         # Build change labels from Common Crawl
recrawl detect-eval                  # Detector P/R (live + CC) → reports/detect.csv
recrawl simulate --budgets 5,10,20   # Freshness-vs-budget curves → reports/freshness.csv
recrawl index                        # Build search index → data/index.pkl
recrawl search "wildfire california" # Ranked search (zones: title:, site:; --bare, --bm25)
recrawl eval-search data/queryset.jsonl --k 5   # Mean P@k ablation → reports/search_eval_*.csv
```

## Datasets & background jobs

- `data/recrawl.db` — live crawl history (`recrawl status` to inspect).
- `data/loop.log` — live-loop log (background: pid on the machine).
- `data/cc_label.log`, `data/cc/labels.jsonl` — Common Crawl snapshot pairs.
- `data/queryset.jsonl` — 24 judged queries (binary relevance) used for search P@k.
- `data/reports/*.csv` — detector P/R, freshness curves, search P@k.

## Evaluation

All tables are regenerated by the CLI commands above; CSVs live in `data/reports/`.
Snapshot date: 2026-10.

### 1. Change detector

Against **live volatile-stripped truth** (n = 29,579 observations):

| method | precision | recall | F1 | acc |
| --- | --- | --- | --- | --- |
| shingle (k=5, τ=0.85) — ours | 0.999 | 0.493 | 0.660 | 0.949 |
| raw byte-hash — baseline | 0.987 | 1.000 | 0.993 | 0.999 |

Against **Common Crawl payload digests**: 2 snapshot pairs (aljazeera.com/news across
CC-MAIN-2026-30→34→39) — both changed; shingle and stripped-hash both agree with the
digest. Anecdotal consistency, not a measured table.

### 2. Freshness vs crawl budget

Replay of the 61-pass recorded history under each policy; `budget` = fetches **per pass**.
`missed` = changes still unfetched at the horizon; `age` = total hours each change went
unfetched (lower better for both):

| budget/pass | ~fetches | rr miss | proposed miss | oracle miss | rr age (h) | proposed age (h) | oracle age (h) |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 2 | 120 | 2495 | 2495 | **1676** | 19845 | 19845 | **10038** |
| 5 | 300 | 2003 | 2003 | **1818** | 12564 | 12564 | 13618 |
| 10 | 600 | 1688 | **1459** | **1308** | 11481 | **10857** | 12248 |
| 20 | 1200 | **356** | 652 | 423 | 8338 | 8629 | **6010** |
| 40 | 2382 | 316 | 348 | **96** | 4960 | **4740** | **2020** |

The proposed policy separates from round-robin where the budget binds (≤10/pass); at
saturated budgets all policies converge (the live loop runs saturated today — the benefit
is measured counterfactually). Full honest caveats in REPORT.md §6.

### 3. Search P@k (24 judged queries, 483-doc index)

| method | P@1 | P@3 | P@5 |
| --- | --- | --- | --- |
| tf-idf (lnc.ltc, no zones) | 0.792 | 0.569 | 0.475 |
| + title zones (weight 2.0) | 0.833 | 0.556 | 0.483 |
| + g(d) (importance + freshness, α=β=0.01) | 0.792 | 0.556 | 0.475 |
| BM25 baseline | 0.875 | 0.597 | 0.492 |

Zones help the top hit; the quality blend preserves meanwhile re-ordering near-ties; BM25
leads on topical P@1. Judgments are self-authored (24 queries, binary) — see REPORT.md §6.
